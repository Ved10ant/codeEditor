# Docker + AWS Collaborative Code Editor 🚀

A real-time collaborative code editor built with React, Monaco Editor, Yjs, Socket.io, Docker, and AWS deployment architecture.

This project is currently under development and is being built while learning real-world DevOps, containerization, and cloud deployment workflows.

---

# 📌 Project Status

🚧 Ongoing Project  
⚡ Active Development  
🛠 Features Being Added Continuously

# ✨ Features

- Real-time collaborative code editing
- Monaco Editor integration
- Multi-user synchronization using Yjs
- WebSocket communication with Socket.io
- Dockerized frontend and backend
- AWS ECS deployment setup
- Infrastructure configuration
- Scalable architecture
- CI/CD ready structure
- Responsive IDE-style UI
